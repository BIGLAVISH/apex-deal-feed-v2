GitHub + Netlify Workflow

  1. Upload this folder to GitHub.
  2. Connect GitHub repo to Netlify.
  3. Edit data/deals.json daily or upload CSV inside the app.
  4. Netlify auto-redeploys after GitHub changes.
  5. Open on phone and Add to Home Screen.
